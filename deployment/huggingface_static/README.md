Free static demo. Image and video inspection, live camera sampling, QR/barcode decoding, built-in sample inputs, and local-only browser history run in the visitor's browser. It uses the full 100-epoch EXP-002 YOLOv8n checkpoint exported to ONNX (320 input). It is trained only for six NEU-DET steel defect classes. No user image is uploaded to a model server by this client-side demo.
